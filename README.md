# Document Extractor

Скрипт на Python для автоматического извлечения ключевых полей из документов трёх форматов: **PNG**, **PDF** и **DOCX**. Поддерживает русский и английский языки (OCR через Tesseract).

## Что извлекается

Из каждого документа скрипт пытается вытащить четыре поля:

| Поле | Описание | Пример |
|---|---|---|
| `Номер документа` | Номер акта, УПД или справки | `118`, `АБ 12-34` |
| `Номер договора` | Номер договора или основание | `24/03/15-01` |
| `Дата` | Дата документа | `28.01.2026` |
| `Итоговая сумма` | Сумма в рублях | `12345.67` |

Для каждого поля реализована цепочка регулярных выражений: сначала ищется точное совпадение по ключевому слову (`№`, `Договор`, `Дата`, `руб`), затем — запасные варианты по формату. Если ничего не найдено, поле остаётся `None`.

## Поддерживаемые форматы

| Формат | Модуль | Как читается |
|---|---|---|
| `.png` | `Rabota_s_png.py` | Tesseract OCR (`rus+eng`) |
| `.pdf` | `Rabota_s_pdf.py` | Сначала текстовый слой PyMuPDF; если текста нет или он нечитаем — рендер страниц в 300 DPI и OCR |
| `.docx` | `Rabota_s_docx.py` | Параграфы и таблицы через `python-docx` |
